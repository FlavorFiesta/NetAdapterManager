## 二、多语言功能

### 语言与设置

- 建议首批：简体中文、繁體中文、English；设置中另提供“跟随系统”。语言选项使用各自本地名称，便于用户切回。
- 新增“设置 → 语言”，保存选择，重启后仍有效。首版以切换后即时刷新界面为验收目标，不丢失编辑中的 IP/DNS、选中网卡、预设筛选或批量选择。
- 网络写入/回滚期间禁用语言切换；结束后恢复，避免操作提示中途混用语言。
- 覆盖主窗口、预设编辑/总览、设置、确认框、校验提示、状态摘要、错误提示及安装器自定义文字。系统原生错误保留原始内容，外层解释可翻译；内部诊断事件使用稳定标识。
- 不翻译用户预设名称、自定义分组名称、系统网卡名称和实际 IP/DNS 值。
- UI 资源集中管理，统一资源键与参数占位符；缺失资源回退到英语，测试检查三种语言的键、占位符及复数表达。

### 安装时默认语言

**可以实现系统显示语言预选，同时每次显示语言选择框让用户更改。** Windows 显示语言只是界面偏好，不据此推断国籍或所在地。

计划配置：

```ini
[Setup]
LanguageDetectionMethod=uilanguage
ShowLanguageDialog=yes
UsePreviousLanguage=no
```

- `[Languages]` 加入英语、简体中文和繁体中文，英语放在第一项，作为不支持的系统语言的回退。
- `uilanguage` 使用当前用户 Windows 显示语言，避免以地区或日期格式代替显示语言。
- `ShowLanguageDialog=yes` 保留用户改选机会；`UsePreviousLanguage=no` 满足“每次默认系统语言”的要求，避免升级安装默认复用上一次选择。
- Inno Setup 对简体/繁体有独立匹配规则。应用内也须区分 zh-Hans、zh-Hant 及地区变体；例如 zh-CN/zh-SG 匹配简中，zh-TW/zh-HK/zh-MO 匹配繁中。无法识别时回退英语。
- 本地化启动应用描述、快捷方式显示名等自定义文字，并核对新增翻译文件的版本和分发许可。保持 AppId、内部产品标识及默认安装路径稳定；验证升级后不会出现旧语言快捷方式残留或重复。
- 无交互安装支持显式 `/LANG=`，不依赖语言选择窗口。

### 安装语言与应用语言衔接

| 情况 | 应用语言规则 |
| --- | --- |
| 已存在有效语言设置，包括“跟随系统” | 始终保留，升级安装的语言选择不覆盖它 |
| 首次安装、没有应用设置 | 将安装器最终选择的语言作为首次启动默认值；用户可在设置里改为其他语言或“跟随系统” |
| 便携版首次启动，没有设置或安装语言种子 | 跟随当前运行用户的系统显示语言 |
| 设置值不受支持 | 安全回退并允许重新选择，不影响网络或预设数据 |

安装器只写独立的初始语言种子，不直接覆盖应用设置；应用成功保存用户选择后不再用种子覆盖。必须验证跨用户 UAC 提权时的配置作用域，避免把提权账号的语言当成原用户的选择。语言设置与预设备份恢复相互独立。

### 必须先做的兼容工作

1. **分组标识与文字分离。** 目前“全部分组”“未分组”同时参与筛选、删除保护和持久化。引入稳定系统标识；“全部分组”仅作为筛选项。迁移旧预设时识别已有系统分组，保留自定义名称，防止翻译后丢组或误删。迁移写入前备份，失败保持旧数据可读；明确新格式与旧版本的回退限制。
2. **语言与命令解码分离。** `NetworkService.CreateNetshEncoding` 当前依赖 CurrentUICulture。改成独立的系统命令输出处理路径，并验证不同 Windows 代码页下的真实输出；不简单假定某一种代码页恒定正确。切换应用语言不得改变命令参数、网卡定位或错误解码。
3. **配置与格式保持稳定。** UI 语言不改变 JSON 枚举/属性、GUID、IP/DNS 输入与网络命令格式。日期时间可按展示规则本地化。
4. **布局适配。** 检查英文长文案、繁体字体、最小窗口宽度、高 DPI、快捷键、键盘焦点与屏幕阅读器名称。

## 三、多主题功能

### 主题与设置

- 新增“设置 → 外观 → 主题”，首批提供常见的浅色、深色两套主题，以及“跟随系统”模式；首次启动默认跟随系统。
- 浅色使用明亮背景、深色文字；深色使用深灰背景、浅色文字。两套主题保持统一的蓝色强调色与操作布局。
- 手动选择立即生效并保存，重启和升级后保留；跟随系统模式在 Windows 应用颜色模式变化时自动更新。系统偏好无法读取时回退浅色。
- 与语言设置独立：切换主题不改变语言、网络配置、预设、输入草稿、筛选或当前选中项，不重新创建整个主窗口。
- 响应系统高对比度设置，优先保证可读性；退出高对比度后恢复用户原有主题偏好。
- 首批聚焦上述常见选项，自定义配色、主题下载和主题编辑器留待后续版本评估。安装器沿用其原生外观，主题选择放在应用设置中。

### 实现与覆盖范围

- 建立统一颜色与画刷资源，按背景、卡片、正文、次要文字、边框、强调色和状态色组织；控件动态引用资源，避免各窗口硬编码颜色。
- 覆盖主窗口、设置、预设编辑和总览，以及应用内弹窗、菜单、提示、列表、输入框、滚动条和图标；同时检查悬停、按下、选中、禁用、焦点和校验错误状态。
- 系统原生对话框遵循系统支持的外观；验收时明确其边界，避免将其计作应用主题已覆盖。
- 成功、警告和失败同时使用文字或图标表达，不能只靠颜色区分；所有主题下保证正文、输入值和键盘焦点清楚可见。
- 启动时尽早加载已保存主题，减少深色模式下白色背景闪现；系统主题变化通知须安全切回 UI 线程，并在退出时解除订阅。
- 主题设置与语言设置共用可靠的偏好存储，但独立校验和回退；无效主题值不阻断启动，也不覆盖其他有效偏好。

## 四、实施顺序与验收门槛

| 阶段 | 交付 | 必须通过的检查 |
| --- | --- | --- |
| 1. 可靠性修复 | R1–R3 修复与回归用例；R4 可验证的超时/写入互斥方案 | 无效备份不替换原文件；有效备份恢复损坏库；失败后实际状态刷新且原错误保留；损坏预设不阻断网卡；取消/超时不会导致重叠写入 |
| 2. 本地化与主题基础 | 语言服务、主题服务、文字与画刷资源、设置存储、系统分组迁移、命令解码隔离 | 旧数据迁移与重复迁移安全；无效语言/主题可独立回退；资源完整；无语言或主题相关网络行为差异 |
| 3. 应用与安装器 | 三语言界面、浅色/深色/跟随系统、即时切换、安装默认语言与首次启动衔接 | 安装选择/应用语言一致；升级保留偏好；系统主题变化可响应；所有应用窗口可切换且草稿与选择不丢失 |
| 4. 发布验收 | v1.5.0 候选包、说明、校验值 | 严格 Release 构建、既有自测及新增回归、界面验收、包内容隐私检查、安装/升级/卸载验收；通过后才发布 |

语言验收矩阵至少覆盖：

- 简中、繁中、英文、未支持语言的系统；系统显示语言与地区格式不同。
- 默认预选、手动改选、`/LANG=` 静默安装；首次安装与从 v1.4.12 升级。
- 已有应用设置、无设置、设置损坏、便携版、跨用户提权启动。
- 三种语言间相互切换、跟随系统、缺资源回退、长文字与高 DPI。
- 故障提示、回滚失败、网卡消失、预设损坏等状态下的本地化与数据显示。

主题验收矩阵至少覆盖：

- 浅色、深色及跟随系统；运行中切换系统应用颜色模式；手动主题不被系统变化覆盖。
- 三种语言分别搭配浅色与深色，检查所有应用窗口、弹窗及控件交互状态；同时验证高对比度进入与退出。
- 首次启动、重启、从 v1.4.12 升级、无效设置及便携版；检查偏好保存与启动闪白。
- 最小窗口尺寸、高 DPI、键盘操作；检查文字、图标、选中项、错误提示和焦点的可读性。
- 编辑未保存、预设筛选/批量选择、网络操作进行中及故障提示显示时切换主题，确保输入与操作状态不丢失、不触发网络写入。

自动化网络测试继续使用隔离模拟。需要验证真实驱动/WMI 边界时，在专用虚拟机或可牺牲测试网卡中进行，不对日常上网网卡执行写入测试。

实际实施涉及程序资源、设置与安装脚本，**需要更新版本并重新生成安装包和便携包**。仅编写本计划不需要重新打包；现有 v1.4.12 发布物保持原样。若多语言准备时间较长，可先单独发布可靠性修复补丁，再发布 v1.5.0。
