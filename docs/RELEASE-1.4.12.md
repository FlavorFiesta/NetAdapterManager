# 1.4.12 发布说明

日期：2026-10-27

修复 1.4.11 复审发现的网卡身份、退出保护、命令超时、完整地址验证和预设存储问题，并减少不必要的网络写入。

## 修复与改进

- 启用/禁用网卡严格按 GUID 定位，找不到原网卡时停止，不再按旧接口索引匹配其他网卡。
- 应用配置、复核、回滚或保存预设期间关闭主窗口，会等待操作完成再退出。同一用户只允许一个实例运行。
- netsh 同时读取标准输出和错误流，支持超时与取消。必须确认旧进程退出后才开始恢复；退出状态不确定时禁止继续写入。
- 常规应用与回滚均验证完整 IPv4 地址集合。附加地址未生效时触发恢复；只修改 DNS 时不重写静态 IP。
- 网卡枚举有读取超时；恢复不依赖本地管理地址元数据文件，避免本地文件不可读导致无法读取系统状态。
- JSON 读取失败明确报错、保留原文件并阻止覆盖。保存采用唯一临时文件、原子替换和上一份 `.bak` 备份。
- 预设与分组合并为 `preset-library.json`，一次提交，失败不改变原内存数据。新增“恢复备份”入口，同时恢复预设和分组。
- 网络测试逐条模拟 set/add 命令，CI 新增存储失败、预设迁移、单实例、进程超时和取消回归。

## 升级与数据恢复

升级前保留完整程序目录。1.4.12 首次读取旧 `presets.json`、`preset-groups.json`，首次成功保存时创建统一库；旧文件保持不变。没有程序目录旧数据时，继续兼容读取 `%AppData%\NetAdapterManager` 的旧数据。

统一库建立后不再重新导入旧文件。降级到 1.4.11 不会读取统一库中的后续变更。

“恢复备份”恢复上一次保存前的状态，并将恢复前文件另存为 `.corrupt-*`。第一次建立新文件前没有上一版备份；旧版文件仍保留。
