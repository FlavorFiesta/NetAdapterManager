# NetAdapterManager v1.6.3

2026-11-12。本地 UI 修正版，尚未发布 GitHub。

- 统一预设筛选控件高度，增加按钮行间距；分组和批量工具可展开收起，明确单项选择与批量勾选的用途。无对应选中项时禁用导出。
- 网卡选择固定在配置区顶部；当前实际配置可展开查看，底部空状态行折叠，释放编辑空间。
- 取消常驻黄色说明，改为默认收起、可随时展开与收起的操作说明。真实错误和操作风险仍正常显示。
- 静态 DNS 留空时显示明确的空值说明。系统静态 IPv4 + 自动 DNS 被编辑器调整时，标明尚未应用，避免误报与系统状态一致。
- 窗口图标使用完整 256px PNG，安装包/EXE 保留多尺寸 ICO；放大网络图形主体，避免加载小帧造成任务栏图标过小。

验证：严格 Release 构建、隔离回归，以及三语言与两种主题的截图检查。新增 DNS 调整、导出选择状态、图标分辨率和说明折叠检查。本轮不写真实网卡；真实多显示器 DPI、任务栏缓存与安装升级行为仍需实际环境验收。
