# v1.6.0 更新计划

日期：2026-10-30。基线：已发布的 v1.5.2。

## 先交付 v1.5.3 客户问题修复

- 修复禁用或断开连接的网卡未显示系统已保存的静态 IPv4、掩码和网关的问题。
- 排查系统已保存配置与运行时状态混用导致的 DNS 展示错误、配置实际生效但复核失败；分别验证静态 DNS、自动 DNS、空 DNS 和附加地址。
- 真实验收仅使用已确认空闲、无默认网关的测试网卡，保存原始状态并恢复；检查当前联网网卡与默认路由不变。
- 增加隔离回归、明确读取来源与复核差异，构建独立补丁包，避免客户修复等待功能开发。

## v1.6.0

| 优先级 | 项目 | 范围与验收 |
| --- | --- | --- |
| 高 | 配置变更预览 | 展示准确目标网卡及 IP、网关、DNS 当前值与目标值，仅突出变化；确认后重新检查目标身份与当前状态，不能用过期快照直接写入 |

| 高 | 预设导入与导出 | 单条、选中项和全部导出；导入校验格式、预览重复项、选择冲突策略；跨电脑手动绑定网卡，导入本身不应用网络配置；失败保留原库 |
| 高 | 界面兼容性 | 验证 125%/150%/200% 缩放、多显示器切换、最小窗口、英文 Windows、高对比度、键盘焦点与快捷键；记录实测和未覆盖环境 |

## 发布要求

保留现有 v1 预设库兼容性；三语言与浅色/深色检查；严格构建、隔离回归、默认只读自测、安装/升级验收；发布包无个人运行数据并附 SHA-256。真实网络测试另行显式选定空闲网卡并保留恢复证据。

IPv6、托盘快捷切换、按网络环境自动应用预设留待独立评估。

## 2026-10-30 本地实现进度

v1.5.3 已完成源码/包对应、安装包只读解包与 SHA-256 收尾，详见其发布说明。v1.6.0 已实现预览与过期状态拒绝、按网卡保留草稿、还原、预设交换及手动绑定、PerMonitorV2 和工作区适配。实现范围与验收边界见 [本地候选版说明](RELEASE-1.6.0.md)。真实多显示器、Windows 高 DPI 切换及英文 Windows 仍需实机覆盖，不标记为已通过。v1.6.1 范围不变。

最终本地验收：严格构建零警告零错误；70 项隔离回归、102 项默认自测通过；六组语言/主题、48 张截图通过；独立 AppId 三语言安装/重装/卸载与 v1.5.2 升级覆盖通过。安装包/便携包各 479 个载荷文件字节一致，SHA-256 已生成并复核。源码和构建证据保存在本地 artifacts/audit-1.6.0，仍未提交或发布 GitHub。在线 NuGet 漏洞审计未完成，其他实机验收边界保持上文说明。
