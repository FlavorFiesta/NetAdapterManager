# v1.5.0 本地候选版

完成日期：2026-10-29。本页为本地候选版历史记录；累计更新纳入 [v1.5.2](RELEASE-1.5.2.md)，1.5.0 不单独发布。

## 更新内容

- 新增“设置”：简体中文、繁体中文、英语、跟随系统；应用界面即时切换，偏好自动保存。
- 新增浅色、深色、跟随系统主题，适配系统高对比度配色；调整英文长文案和按钮测量，切换时保留编辑内容。
- 安装器默认按 Windows 显示语言预选，允许手动改选。首次启动沿用安装语言；已有 `settings.json` 的选择不被升级覆盖。
- 恢复预设备份前校验版本、必需集合和空记录，拒绝不兼容备份，当前库保持不变。
- 配置/回滚失败后读取实际网卡状态；读取失败清除旧快照并标记未知，保留原操作错误与同一网卡的编辑草稿。
- 预设损坏不再阻断初次读取网卡，继续保护故障文件。
- WMI 网卡启停增加 15 秒等待上限；超时后保留未完成操作的写锁并禁止后续写入，不把超时视为系统操作已停止。
- 网络命令输出编码与界面语言分离。

## 数据兼容

预设库仍使用 v1 格式。“全部分组”和“未分组”作为既有格式的固定标识保留，显示文字通过独立资源翻译；不需要迁移或重写旧库。用户命名的分组、预设及网卡名称不翻译。

语言、主题保存在程序目录的 `settings.json`，安装器的 `install-language.txt` 只用于没有设置时的初始选择。恢复预设备份不改变外观偏好。损坏设置在用户保存新选择时另存保留。

快捷方式统一使用 NetAdapterManager 名称；正式升级清理旧简体中文快捷方式，避免改选安装语言后出现重复入口。
