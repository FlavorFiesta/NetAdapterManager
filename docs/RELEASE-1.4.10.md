# 1.4.10 发布说明

日期：2026-10-20

本版完成首次开源发布准备。为区分原有 1.4.9 二进制和新增许可材料的发布包，
版本提升至 1.4.10。网卡配置、预设和升级保留用户数据的行为保持一致。

## 变更

- 项目采用 MIT，补齐第三方版权、许可和声明；发布时按实际依赖版本收集到 ZIP 与安装包。
- 添加 `.gitignore`，排除运行数据、日志、历史截图、编译缓存和内部工作记录。
- 公开截图使用虚构数据重新渲染，原始本地数据保留。
- 打包不再清空输出目录，只覆盖本版本的两个指定产物；拒绝越界目录及链接路径，图标生成失败立即停止。
- 默认自测通过虚构快照与命令捕获器验证 DHCP/DNS 幂等性，不进入真实 Apply / 回滚流程。
- 补充构建依赖、安装器用途说明、更新记录和 GitHub Actions 编译检查。

## 验证

- 主程序与自测项目 Release 构建通过。
- 按 `.gitignore` 筛选的 58 个公开源码文件复制到独立目录后，恢复依赖并以 `-warnaserror` 构建成功：0 警告、0 错误；不依赖项目原有 bin/obj，依赖包可来自全局 NuGet 缓存。
- SelfTest：32 通过、0 失败；真实写入测试未执行。
- 全功能只读脚本：13 通过、0 失败（使用已编译输出，跳过重复构建）。
- UI 冒烟：主窗口、预设编辑及管理、双击编辑、批量勾选、提示计时、置顶检查通过。
- Wi-Fi 网卡状态、IPv4 和 DNS 的前后快照一致。
- 四种危险输出路径被拒绝；打包保留输出目录中的无关文件，临时 staging 清理成功。
- ZIP 484 项，包含 20 项许可/声明文件，未包含预设、管理地址 JSON、日志或 PDB。
- 安装包在隔离目录静默安装成功，版本为 1.4.10.0，许可文件完整；卸载成功且没有残留文件。未启动主程序。
- NuGet 官方源的直接及间接依赖查询未报告已知漏洞；此结果不代表完整安全认证。
- 打包时沙盒内曾出现 NU1900 网络警告；随后已在可联网环境完成依赖查询。

构建环境：Windows x64、.NET SDK 8.0.424、运行时 8.0.30、Pillow 11.1.0、Inno Setup 6.7.3。
