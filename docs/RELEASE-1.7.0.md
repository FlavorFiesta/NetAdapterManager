# NetAdapterManager v1.7.0

2026-11-12，本地运维界面重做版，尚未发布 GitHub。

## 界面与交互

- 网卡选择改为紧凑单行，选中后显示 MAC/IP；异常状态使用小红点和悬浮说明，隐藏虚拟网卡开关靠近标题。
- 左侧负责网卡配置，右侧为独立的预设模板库。静态输入框按 DHCP/DNS 模式自动折叠，操作按钮随表单滚动。底部状态、版本和刷新时间合并，中性灰色滚动条。
- 实时生效配置和未生效的系统保存配置使用不同标题。CIDR 标签说明输入前缀长度，模板搜索提供占位提示。模板卡片显示创建时间、可选绑定 MAC 和“不指定 DNS”。
- 应用配置、保存模板分别说明效果，DNS 操作说明改为悬浮提示。使用低饱和蓝色，保留三语言、浅色/深色主题。

## 模板风险与权限

- 应用模板的目标始终是当前选中的网卡；原绑定不同会显示黄色警告。应用前确认模板名称、目标和覆盖风险，之后仍有配置差异预览及过期状态检查。
- 单项及批量删除模板均需确认；确认窗口默认选择取消，支持缩放。绑定匹配的模板有高亮标记。
- 普通用户启动时只读；修改网络配置需右键程序选择“以管理员身份运行”。界面和网络服务写入入口均检查权限。旧版启动必弹 UAC 的行为改为按需提权运行。

## DHCP 附加地址

- 高级区支持每行一个 IPv4/前缀，最多 16 个；依据 [Microsoft netsh 文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netsh-interface)使用 Windows DHCP/静态地址共存和 skipassource，保留 DHCP 主地址与网关。
- 手动 DNS 是接口级设置，会替代该接口的自动 DNS，不是向 DHCP 解析器列表中追加。
- 读取手动地址来源、校验、差异预览、状态复核和失败回滚纳入原有流程；不能确认地址来源时不宣称复核成功。Windows 不支持共存命令时会报错并尝试恢复。
- 模板保存、编辑、导入导出及去重均保留附加地址。旧 v1 模板可继续读取；包含附加地址的新模板应使用 1.7.0 或更新版本。
- 共存功能标志启用后会保留；回滚恢复地址及 DNS，不恢复该接口功能标志的先前值。

## 界面显示设置

- 小/默认/大/超大预设，自定义整体缩放（75–175%）和独立字体缩放（85–150%）。默认跟随系统 DPI，关闭后自定义整体缩放会补偿系统 DPI，避免重复放大。
- 设置区实时预览，应用后所有窗口即时更新并持久保存；一键重置立即恢复默认。弹窗与 tooltip 采用相同显示设置，极小窗口通过滚动访问完整内容。
